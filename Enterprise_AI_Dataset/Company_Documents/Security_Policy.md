# Security Policy

## Access Control

Access is granted using role-based permissions. Employees receive only the systems and data needed for assigned work. Managers review access quarterly.

## Data Handling

Source code, credentials, HR records, client data, and AI evaluation data are confidential. Production secrets must not be stored in code repositories or shared through chat tools.

## Incident Reporting

Suspected security incidents must be reported immediately to the manager and backend owner. Logs, screenshots, and timeline details should be preserved.
