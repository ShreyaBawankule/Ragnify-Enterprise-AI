# Code of Conduct

## Professional Behaviour

Employees must communicate respectfully, support inclusive collaboration, and avoid harassment, discrimination, or retaliation. Feedback should be specific, constructive, and work-focused.

## Collaboration

Team members are expected to document decisions, attend required meetings, review code responsibly, and help unblock colleagues when dependencies arise.

## Conflicts

Conflicts should be resolved first through direct discussion, then with manager or HR support if needed.
